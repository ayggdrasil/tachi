# Tachi — 구현 결과 요약 (해커톤 제출용)

## 무엇을 만들었나
시니어의 옛 사진과 대화를 **기억 그래프(Kùzu 그래프 DB)**로 바꾸고, 그 추억을 중심으로 가족을 다시 잇는 AI 동반자.

| # | 요구사항 | 구현 | 데모 단계 |
|---|---|---|---|
| 1 | 옛 사진 → 문답 → 배경·시기·인물·추억 저장(그래프 DB), 키워드로 회상 | 한 번에 하나씩 묻는 인터뷰 → 장소/시기/인물/사건/감정/키워드 노드·관계로 Kùzu에 저장 → “불국사” 한 단어로 회상(그래프 경로 + Cypher) | 2–5, 8 |
| 2 | 대화 종류별 가족 공개/비공개 | 건강·추억·일상·기분·여행 카테고리 + 추억별 공개 설정. 서버 코드에서 강제(실시간 전송·과거 메시지·파생 데이터까지 회수) | 6, 11 |
| 3 | 하루 몇 번 먼저 말 걸기 + 가족방에 몇 시에 대화했는지 리포트 | 09:00 / 14:00 / 19:30 능동 대화(지난 추억 기반 또는 새 사진 요청), 21:00 리포트(비공개는 시간만) | 1, 16 |
| 4 | 가족·친지 채팅방 생성, 가상 전화번호부로 초대 | 새 대화방, 12명 가상 전화번호부, 초대 시 시스템 메시지 + 봇 인사. 친족이 아닌 사람에게는 어르신 정보 비공개 | 7 |
| 5 | 공개된 건강 정보 자유 질문 | 7일 혈압·복약·수면·걸음 수. 최신 수치가 위험하면 경고를 항상 먼저 | 10 |
| 6 | “가족에게 공유할까요?” → 감성 요약 전달 | 동의 우선(새 추억은 기본 비공개) → 자녀가 읽는 감성 요약 카드 | 6 |
| 7 | 추억 기반 근처 여행 제안 → OK 시 동선 | 추억 장소 기반 1박 2일, 시니어 친화 동선(계단·휠체어·휴식), 처방 중립 안내 | 9 |
| 8 | Claude Sonnet·Haiku, ChatGPT Terra·Luna 교체 | 런타임 전환 + 모델 상태 점검(응답 속도), 실패 시 오프라인 브레인 자동 대체, 실제 응답 출처 표시 | 15 |
| 9 | 모임 제안 → 아티팩트, 함께 추진, 시간 잡기 → 구성원별 사이드 챗 | 모임 기획서(배경·목적·장소·안건·할 일·담당자) 실시간 공동 편집, 여행에서 바로 기획서 생성, 사이드 챗 일정 조율 → 확정/후보 정책 | 10, 12–14 |
| 10 | 데모 환경: AI 가족 봇 또는 여러 기기 접속 | 가족 봇(“AI 봇” 표시)이 한두 줄씩 대화 참여, LAN QR로 실제 폰 접속(접속한 역할은 봇이 멈춤), 디렉터 콘솔 | 전체 |

## 품질 루프 결과
- **멀티 에이전트 구성**: 설계·계약·통합·리뷰 판단 = Opus, 구현 = Sonnet 에이전트(서버 코어 / AI 브레인·그래프 / 채팅 UI·시니어 앱 / 가족 앱·디렉터)를 파일 소유권으로 나눠 병렬 실행.
- **GPT‑6.1 Sol (reasoning xhigh) 리뷰 → 개선 루프**: 6.0 → 7.0 → 7.4 → 7.9 → 8.4 (`docs/reviews/round-*.md`). 각 회차 지적을 전부 반영.
- **gstack /autoplan QA** (CEO·디자인·엔지니어링·DX 리뷰, degraded mode): P0 3건·P1 10건 전부 반영 (`docs/qa/autoplan-review.md`).
- **impeccable 디자인 루프**: 1차 감사 13/20 · 비평 29/40 → 52개 수정 항목 + GPT 화면 지적 반영 → 정적 소스와 실제 화면 7곳(시니어 라이트/다크, 가족방 모바일/데스크톱/다크, 디렉터, 랜딩)에서 **검출 0건** (`docs/design/`).
- **테스트**: 단위(브레인·그래프·프로바이더) + 플로우·보안·개인정보·회귀·P0·종단간 스모크 — `npm test`.
- **데모 리허설**: 디렉터 자동 진행 16단계 — 오프라인 54초, 라이브 ChatGPT 82초(Terra 12건 + 모델 교체 후 Luna 2건 + 규칙 응답 2건, 오프라인 대체 0건).
